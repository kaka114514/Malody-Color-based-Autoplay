# 基于颜色检测的 Malody 自动游玩工具 —— 设计文档

- 日期：2026-08-14
- 项目位置：`D:\App\Game\color-based Autoplay`
- 目标游戏：Malody（`D:\App\Game\Malody\malody.exe`，普通权限启动）
- 交付形式：先交付 Python 脚本，功能稳定后再打包为独立 exe

## 1. 背景与目标

编写一个带交互界面的 Windows 桌面工具，通过屏幕颜色检测实现 Malody 下落式音符的自动游玩：

- 在判定线高度、每个判定列的位置设置检测点；
- 运行时检测点颜色从「背景色」变为任意一种「按键颜色」时，按下该列绑定的按键；
- 颜色变回背景色时立即松开按键。

目标检测频率：**每秒至少 100 次**（单帧 ≤ 10ms）。

## 2. 功能需求

### 2.1 选择游戏窗口

- 点击按钮后进入「选择窗口」模式，鼠标变为十字；
- 左键点击游戏窗口任意位置，通过系统 API 取得窗口句柄与窗口矩形；
- 选择成功后，在游戏窗口边缘绘制 **5px 宽的细黄线框**；
- 窗口拖动、缩放时黄框实时跟随（每 100ms 轮询一次窗口矩形）；
- 窗口最小化或不可见时，隐藏覆盖层；恢复后重新显示。

### 2.2 调整判定线高度

- 点击按钮进入设置模式，在游戏窗口垂直正中间绘制一条 **3px 宽的红色横线**；
- 全局按键（焦点不在本工具时也生效）：
  - `1`：红线整体上移 1px；
  - `2`：红线整体下移 1px；
  - `3`：结束设置（红线保留显示）；
- 设置模式中，左键点击游戏窗口内任意位置，红线跳到该点击的 y 坐标；
- 按钮旁输入框可直接输入数字，按窗口内相对 y 坐标（像素）设定高度；
- 红线持续显示，并在每个蓝点 x 位置留缺口（见 §4.1）。

### 2.3 选择列

- 按钮旁先输入列数（如 `4`）；
- 点击按钮进入设置模式，左键在游戏窗口内点击位置，只取横坐标，纵坐标取判定线高度；
- 每点击一次生成一个**蓝色小圆点预览**（空心圆环，见 §4.1）；
- 全局按键：
  - `1`：当前选中列向左微调 1px；
  - `2`：当前选中列向右微调 1px；
  - `3`：结束设置（蓝点保留显示）；
- 点击已有蓝点可重新选中该列；新添加的列自动成为当前选中列；
- 若已添加列数达到设定列数，继续点击提示「列数已满」；
- 按钮旁另一输入框输入每列按键绑定，如 4 键模式输入 `DFJK`，四个检测点从左到右依次绑定 D/F/J/K；
- 绑定字符串按字符逐一对应；也支持空格分隔的键名（如 `Space F J K`）。
- 绑定数量必须等于列数，不匹配时提示错误且不应用。

### 2.4 吸取背景颜色

- 点击按钮进入吸管模式，按键 `1` 激活吸管状态：
  - 鼠标指针变为吸管图标；
  - 左键点击屏幕任意位置，吸取该像素颜色；
  - 颜色以小块形式显示在按钮旁，**点击色块可删除**；
- 支持多个背景色样本（应对渐变背景），检测时命中任一背景色即视为背景。

### 2.5 吸取按键颜色

- 按钮旁先输入颜色数量（如 `2`）；
- 点击按钮进入吸管模式，按 `1` 激活吸管状态，左键吸取颜色后追加到列表尾部；
- 再次按 `1` 可继续吸取下一个颜色，直到达到设定数量；
- 颜色块显示在按钮旁，点击色块可删除；
- 检测时命中任一按键颜色即视为按键颜色。

### 2.6 调整延迟

- 输入框直接输入数值（单位 ms，允许正负数）；
- 运行中全局按键：
  - `4`：延迟减 5ms（提前 5ms）；
  - `5`：延迟加 5ms（推后 5ms）；
- **延迟语义**：正数 = 检测到颜色变化后等待 N ms 再按下；**负数等效为 0**（检测到后立即按下）。

### 2.7 运行 / 暂停 / 保存

- **运行**：
  - 先将游戏窗口设为前台（SetForegroundWindow）；
  - 识别循环开始，仅读取每个蓝点中心位置的像素；
  - 颜色从背景色变为任意按键颜色 → 按下对应按键（按延迟调度）；
  - 变回背景色 → 立即松开；
  - 长按音符天然支持（颜色持续为按键色则持续按住）；
- **暂停**：停止识别循环，立即松开所有被按住的按键；不关闭程序、不关闭覆盖层；
- **保存**：将除游戏窗口外的全部设置写入程序文件夹内 `config.json`，下次启动自动加载。

## 3. 技术选型

**方案 A（选定）：Python 3.11 + tkinter + pywin32 + Pillow**

- tkinter：控制界面与透明覆盖层；
- pywin32：窗口枚举/追踪、全局低级键盘鼠标钩子、SetForegroundWindow、SendInput 按键注入；
- Pillow（PIL.ImageGrab）：抓取屏幕小区域像素。

选择理由：

- 检测不抓整屏，只抓判定线高度窄条带，单帧 3~5ms，实测可到 200~300 次/秒，满足 ≥100 次/秒；
- 依赖轻、启动快、后续 PyInstaller 打包简单；
- pywin32 对窗口 API 覆盖完整。

### 4.1 覆盖层绘制与截屏污染的规避（关键设计）

覆盖层窗口（`WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`，置顶、点击穿透）绘制的内容会出现在屏幕截图中，可能污染检测像素。对策：

- **蓝点为空心圆环**：外圈蓝色（线宽 2px、外径 5px），内部为透明色，中心留 ≥ 6px 透明圆孔；
- **红线在蓝点位置断开**：每个蓝点 x 坐标左右各留 6px 缺口；
- **检测点 = 蓝点中心像素**：位于透明圆孔内，截图中即游戏画面本身；
- 黄框在窗口边缘，与检测点（窗口中部）不重叠，无影响。

### 4.2 检测与性能

- 独立检测线程，与 GUI 线程完全分离；
- 每帧用 `ImageGrab.grab` 抓取包含所有检测点的最小矩形（判定线一行，约 窗口宽 × 5px），一次性读取所有蓝点中心像素；
- 单帧开销：BitBlt 1~3ms + 颜色判断 <1ms，目标 ≥ 100 次/秒；
- 检测循环不 sleep（或仅 1ms），以保证响应速度；
- 延迟通过调度器实现，不阻塞检测循环（见 §4.3）。

颜色匹配：

- 背景色集合、按键色集合，均为多个 RGB 样本；
- 匹配采用 RGB 欧氏距离，默认容差 40（0~255 标度），可在配置中调整；
- 判定优先级：命中按键色 > 命中背景色 > 都不命中（保持上一帧状态，避免中间色闪烁）。

### 4.3 识别循环与延迟调度

状态模型：每列维护 `desired[i]`（按下/松开）与 `pressed[i]`（实际按键状态）。

- 每帧采样后更新 `desired[i]`：
  - 命中按键色 → desired = 按下；
  - 命中背景色 → desired = 松开；
  - 都不命中 → 保持原 desired；
- 按下沿：`desired` 从松开变为按下时，记录 `trigger_time = now + delay`（delay 按 §2.6 语义，负数按 0）；
- 松开沿：立即执行 SendInput 松开；
- 调度器 tick（1ms）：到达 `trigger_time` 且该列此刻仍为按下期望时执行 SendInput 按下；若期间已变回背景，则取消该次按下（避免误按）；
- 暂停时：停止循环，立即松开全部按键。

按键注入：`SendInput` 发送 keydown/keyup。字符按键用 VK 码；特殊键名（如 Space、Shift）走映射表。

### 4.4 全局输入钩子

- `SetWindowsHookEx(WH_KEYBOARD_LL)` 在独立线程运行消息泵，监听 `1/2/3/4/5`：
  - 判定线模式：1=上移、2=下移、3=结束；
  - 列模式：1=左移、2=右移、3=结束；
  - 吸管模式：1=激活/继续吸管；
  - 运行模式：4=延迟-5ms、5=延迟+5ms；
- 同一键在不同模式下的含义由当前模式决定；
- 鼠标左键取色/选取由低级鼠标钩子或 `GetAsyncKeyState` + `GetCursorPos` 轮询实现；
- 注意：若游戏以后改为管理员权限启动，本工具也必须以管理员启动（界面给出提示）。

### 4.5 界面布局（tkinter）

纵向排列，每个功能占一行，底部三个按钮：

```
┌────────────────────────────────────┐
│ [选择游戏窗口]                      │
│ 判定线高度 [输入框]  [设置按钮]      │
│ 列数 [输入框]  按键 [输入框] [设置]  │
│ 背景颜色 [吸色按钮]  [色块...]      │

```

## 5. 配置文件（config.json）

```json
{
  "judgement_line_y": 0.78,
  "column_count": 4,
  "key_string": "DFJK",
  "columns": [
    {"x": 0.20, "key": "D"},
    {"x": 0.40, "key": "F"},
    {"x": 0.60, "key": "J"},
    {"x": 0.80, "key": "K"}
  ],
  "background_colors": [[10, 10, 15]],
  "key_colors": [[240, 80, 90], [255, 200, 60]],
  "delay_ms": 0,
  "tolerance": 40
}
```

- 判定线高度与列 x 均存**相对比例**（0~1），窗口大小变化后不失真；
- 游戏窗口本身不保存（每次启动重新选择）；
- 保存/加载采用 UTF-8 JSON，读写失败时提示且不崩溃。

## 6. 错误处理

- 未选择窗口就运行 → 状态栏提示，不启动识别；
- 未设置列/颜色就运行 → 提示缺失项；
- 窗口丢失或最小化 → 自动暂停识别并提示；
- 吸管取色失败、截图失败 → 记录日志并继续；
- 按键注入失败（管理员权限差异）→ 提示用户以管理员启动；
- 全局钩子失败 → 降级为轮询方案并提示。

## 7. 测试方案

### 单元测试（pytest 或内置断言）

- `color_matcher`：容差匹配、背景/按键优先级、边界值；
- `config`：保存→加载 round-trip、非法 JSON 容错；
- `autoplay` 调度逻辑：延迟按下、取消误按、立即松开（纯逻辑部分与窗口解耦）。

### 手动验收清单

- 黄框跟随窗口拖动/缩放；最小化时隐藏；
- 判定线 1/2 微调、左键跳转、数字输入、3 结束、红线保留且蓝点处断开；
- 列添加/微调/选中/结束、蓝点保留；
- 吸管图标、取色、色块删除；
- 延迟 4/5 调整与输入框回显；
- 运行：颜色变按键色按下、变背景松开、长按持续；
- 暂停：停止识别并松开按键；
- 保存后重启自动加载全部设置；
- 检测频率实测 ≥ 100 次/秒（调试日志显示 FPS）。

## 8. 后续打包

- 功能验收通过后用 PyInstaller 打包：`pyinstaller --onefile --windowed main.py`；
- 附带 `cursor.cur` 资源；
- 打包后仍需在目标机器验证全局钩子与按键注入。

## 9. 范围外（本期不做）

- 多窗口同时游玩；
- 音符预测/提前量超过检测时刻的物理提前（负延迟按 0 处理）；
- 非窗口模式（全屏独占）适配；
- Malody 谱面解析。
