# Malody Color-based Autoplay

基于屏幕颜色检测的 **Malody** 自动游玩工具。在游戏画面上设置检测点，音符到达判定线时自动按下对应按键。

## 功能特性

- 选择游戏窗口并实时跟踪（窗口拖动/缩放时黄框自动跟随）
- 判定线、音符列可视化设置（黄框 / 红线 / 蓝点覆盖层）
- 吸取背景色与按键颜色，颜色数量不限，带容差匹配
- 独立检测线程，DXGI 硬件加速截屏，检测频率 200+ 次/秒
- 延迟微调（正负）、最短按压时长可配置
- 蓝键采集模式：鼠标跟随 2px 绿点，点击游戏读取坐标与颜色
- 多套配置文件（另存为/打开对话框），启动自动加载最近配置
- 全部功能支持全局快捷键

## 环境要求

- Windows 10/11
- Python 3.11

## 安装与启动

双击 `start.bat`（首次会自动安装依赖），或手动运行：

```bash
pip install -r requirements.txt
pythonw main.py
```

## 使用步骤

1. **选择游戏窗口**：点击「选择游戏窗口」，再点击 Malody 窗口，出现 8px 黄色边框。
2. **设置判定线**：点击「设置」，用 1/2 键上下微调、左键点击选高度、或输入框输入像素值，按 3 结束（红线保留）。
3. **设置列**：输入列数和按键绑定（如 `DFJK`），点击「设置列」，在游戏里左键点击每列位置（生成蓝点），1/2 微调、3 结束。按键从左到右对应。
4. **吸取背景颜色**：点击「吸色」，按 1 激活，左键吸取游戏背景颜色。
5. **吸取按键颜色**：点击「吸色」，按 1 激活，左键吸取音符颜色（可吸任意多种）。
6. **调整延迟与最短按压**：输入框直接输入（如 `0`、`-20`、`50`）。
7. **运行**：点击「运行」或按 8，程序将自动识别并按键；按 9 暂停。

## 全局快捷键

| 键 | 功能 |
|---|---|
| 1 / 2 / 3 | 设置模式下微调 / 结束 |
| 4 / 5 | 延迟 -5ms / +5ms |
| 6 | 切换覆盖层显示 |
| 7 | 黄键 / 蓝键（采集模式）切换 |
| 8 / 9 | 运行 / 暂停 |
| Ctrl | 取消吸管与输入状态 |

> 输入框聚焦时数字键仅作为输入，不触发热键。

## 蓝键采集模式

按 7 切换到蓝键模式：

- 边框变蓝，点击游戏不再操作游戏，而是被程序捕获
- 鼠标位置显示 2px 绿点（置顶、点击穿透）
- 状态栏显示点击位置的坐标与颜色值，方便精确定位

## 配置管理

- 「配置」按钮：弹出另存为窗口，可命名保存多套配置（存放在 `configs/` 文件夹）
- 「恢复」按钮：选择配置文件并应用
- 启动时自动加载最近一次使用的配置；关闭程序自动保存当前设置

## 工作原理

1. 每个蓝点是一个检测点（横坐标 = 音符轨道，纵坐标 = 判定线）
2. 检测线程以 200+ 次/秒读取每个检测点的像素颜色
3. 颜色从背景色变为按键颜色 → 音符到达判定线 → 注入对应按键（扫描码）
4. 颜色变回背景色 → 松开按键（长按音符自动支持）

## 常见问题

**游戏内按键没有反应？**

- 确认游戏窗口在前台（必要时按 6 切换覆盖层并置前游戏）
- 确认检测点（蓝点）位置在音符轨道上、红线在判定线上
- 确认背景色和按键颜色吸取得正确

**密集音符会漏键？**

检测频率受显示器刷新率限制。若音符之间在像素上没有间隙（颜色一直保持按键色），纯视觉检测无法区分，可尝试调低最短按压时长。

**光标或窗口异常？**

程序使用普通权限即可；若 Malody 以管理员运行，本工具也需以管理员启动。
